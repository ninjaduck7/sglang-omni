# RTX 5090 / CUDA 12.8 worktree

Base: `b83910176f72dd0666d1e9bdce2c203792a10b4c`. This worktree uses
an editable install and its own Python 3.12.14 environment. Verified with
NVIDIA driver 570.172.08 and the system CUDA 12.8 toolkit on Linux x86_64.

For measured Qwen3-ASR/TTS service results and CUDA Graph replay, see
[the single-GPU runbook](scripts/cu128/README.md).
Newer upstream features tested on this historical branch are tracked in
[the CUDA 12.8 feature matrix](FEATURES-CU128.md).

From this directory:

```sh
source .venv/bin/activate
python scripts/check_cu128.py
sgl-omni --help
```

The check uses synthetic tensors and temporary, locally generated config
metadata. It tests BF16 matmul, the SGLang and FlashInfer RMSNorm kernels,
FlashInfer prefill/decode, FlashAttention 2, and the Triton attention
implementation used by the ASR audio encoder. It does not fetch a model
or start the server. Compiling the kernels the first time requires the local
CUDA toolkit, a C++ compiler, and Ninja (provided in the environment).

On this stack, FlashInfer 0.6.1's standard RMSNorm already uses its CUDA
implementation; it does not read `FLASHINFER_USE_CUDA_NORM`. SGLang 0.5.8
selected `flashinfer` for the synthetic decoder config and `triton_attn` for
multimodal attention on SM120. No SM100-only kernel or global backend override
is configured. The NIXL and Mooncake Python backends import successfully;
cross-process transfers and model-level inference have not been tested.

## Rebuild on this host

Run these commands in a clean worktree with this configuration, with
`uv`, Python 3.12 and CUDA 12.8 available. The constraints file records the
installed package versions independently of the checkout path. Use `uv pip`
from the worktree root so uv reads the source and protobuf overrides in
`pyproject.toml`. PyTorch wheels come from the NJU cu128 mirror, other index
packages from TUNA. Download the separate FlashAttention wheel once and
verify its upstream release digest before installing it:

```sh
uv venv --python 3.12 .venv
source .venv/bin/activate
(
  set -e
  export UV_CACHE_DIR="$VIRTUAL_ENV/.uv-cache"
  wheel=flash_attn-2.8.3+cu12torch2.9cxx11abiTRUE-cp312-cp312-linux_x86_64.whl
  url="https://github.com/Dao-AILab/flash-attention/releases/download/v2.8.3/$wheel"
  dest=$(mktemp -d)
  trap 'rm -rf -- "$dest"' EXIT
  curl -fL --retry 2 "$url" -o "$dest/$wheel"
  printf '%s  %s\n' 4e2f9e39313266b1544b68138b15b91ee6221eccf14f7902b7c6620351340810 "$dest/$wheel" | sha256sum -c -
  export NO_PROXY="${NO_PROXY:+$NO_PROXY,}mirrors.nju.edu.cn,pypi.tuna.tsinghua.edu.cn"
  export no_proxy="$NO_PROXY"
  unset UV_INDEX_URL UV_DEFAULT_INDEX
  uv pip install --python "$VIRTUAL_ENV/bin/python" -c requirements-cu128.lock -e . "$dest/$wheel"
)
python scripts/check_cu128.py
```

The host's `vpn on` shell function can be used for the external URL when
its proxy service is running. Existing CUDA environments are not needed.

`uv pip check` reports one upstream metadata conflict: `descript-audiotools`
requires protobuf <3.20 while this checkout explicitly overrides protobuf
to >=6.31.1,<7 (installed: 6.33.6). The package imports; this does not
validate every codec or optional model path.
